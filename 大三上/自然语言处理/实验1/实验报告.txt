一、研究背景

自然语言处理（NLP）旨在让计算机理解与生成自然语言文本。本实验围绕中文语料的预处理、统计语言模型与分布式词表示展开：
- 涉及领域：中文文本清洗与分词、词频与 N-gram 统计、词向量（Word2Vec）训练、文本相似度计算与可视化。
- 研究方法：
  - 统计方法：词频统计与二元搭配（bigram）揭示词分布与共现规律；
  - 分布式表示：利用 Word2Vec 学习稠密词向量，通过几何距离刻画语义相似与聚类结构。
- 主要问题：
  - 词袋/N-gram 高维稀疏、难以表达语义与长距离依存；
  - 词向量依赖语料规模与参数选择，对低频词与领域迁移敏感，且可解释性较弱。
- 解决路径：
  - 统计模型上使用平滑/回退/插值缓解稀疏；
  - 表示学习上引入更大规模预训练与子词建模（fastText/BERT）提升覆盖与泛化。

二、模型方法

2.1 理论基础和核心概念
- 分布假设：语义相近的词具有相似的上下文分布；
- 词袋模型（BoW）：以词频向量表征文本，忽略词序；
- N-gram：基于马尔可夫假设建模短程依存；
- 词向量（Word2Vec）：将词映射到低维稠密空间，语义相近词距离更近。

2.2 算法/模型的基本原理和工作机制
- BoW：CountVectorizer 统计词频，得到稀疏矩阵用于相似度/下游任务；
- N-gram：滑动窗口拼接相邻 n 个词形成搭配并计数；
- Word2Vec（Skip-gram）：给定中心词预测上下文，最大化目标词在上下文出现概率。

2.3 模型架构（如使用神经网络）
- Word2Vec 为浅层神经网络：输入为 one-hot 词向量，经嵌入层映射到低维，输出层为上下文词概率分布；训练后取嵌入矩阵作为词向量。

2.4 关键数学公式（简要）
- Skip-gram 目标：最大化 \(\sum_t \sum_{-c\le k\le c, k\ne 0} \log p(w_{t+k}\mid w_t)\)；
- 其中 \(p(w_o\mid w_i)=\frac{\exp(\mathbf{v}_{w_o}^{\top}\mathbf{u}_{w_i})}{\sum_{w}\exp(\mathbf{v}_{w}^{\top}\mathbf{u}_{w_i})}\)，实际用负采样近似；
- 训练得到的嵌入向量 \(\mathbf{u},\mathbf{v}\) 即词向量表示（常用输入嵌入）。

2.5 算法流程（伪代码）
- 语料 -> 清洗 -> 分词 -> 统计词频/N-gram -> 切句 -> 训练 Word2Vec -> 保存模型 -> PCA 可视化 -> 相似词/句子相似度评估。

三、系统设计

3.1 实验环境
- 操作系统：Windows 10/11；
- 编程语言：Python 3.8+（实际 3.12 亦可）；
- 开发工具：VSCode/Jupyter；
- 依赖库及版本：jieba、gensim、matplotlib、numpy、pandas、scikit-learn；
- 硬件：常规 CPU 即可，内存越大越利于处理大语料。

3.2 数据集与语料处理
- 数据集：Ci.txt（宋词），1998-01-2003版-带音.txt（新闻）；
- 特点：宋词偏意象与格律，新闻偏实体/主题词与时政经济；
- 处理流程：多编码读取 -> 正则清洗（保留中/字母/数字） -> jieba 分词 -> 过滤空白。

3.3 模型训练
- 切句：按固定窗口将分词序列切成句子列表；
- Word2Vec 参数：vector_size=100，window=5，min_count=5，sg=1，workers=4；
- 训练策略：Skip-gram，默认轮次足以收敛（需时可增 epochs）。

3.4 模型测试与评估
- 相似词：给定查询词输出 Top-K 相似词与相似度；
- 句子相似度：
  - BoW：CountVectorizer -> 余弦相似度；
  - W2V：句内词向量平均 -> 余弦相似度；
- 可视化：PCA 将词向量降至 2D 并标注词。

3.5 系统流程图（文字描述）
- 输入语料 -> 读入与清洗 -> 分词 -> 词频/N-gram 统计与导出 -> 切句 -> Word2Vec 训练与保存 -> PCA 可视化 -> 相似词/相似度评估 -> 输出报告与图片。

  - 新闻：查询“中国/经济/发展/技术”近邻多为实体、经济与技术相关词。

4.2 课程样例测试
- 若样例包含关键词重叠但语义不同，BoW 可能误判相似；
- W2V 对语义相近但词面不同的表达更敏感，能给出更高的相似度。

4.3 结果分析
- 成功案例：主题/语义一致的文本，W2V 相似度较高且近邻合理；
- 失败案例：极低频专有名词、歧义词或新词，因词向量覆盖不足与上下文稀疏导致相似度不稳定。

4.4 改进方案
- 数据：引入更大规模与多样化语料，构建停用词表，做更细清洗；
- 特征：尝试子词建模（fastText）、词形归一、领域自适应；
- 模型：提升维度/窗口、使用更强预训练（如 Chinese Word2Vec/GloVe，或 BERT）；
- 训练：调参与早停、增加 epochs；
- 评估：引入分类/检索等任务化指标与人工评测，系统性对比 BoW/W2V 方案。

五、实验拓展

10. 使用预训练词向量（已实现）
- 目标：比较自训练词向量与预训练词向量的效果差异
- 实现方案：
  - 创建示例预训练词向量：包含60个常用中文词，维度100，用于演示对比
  - 加载预训练模型：`from gensim.models import KeyedVectors; model = KeyedVectors.load_word2vec_format('sample_pretrained.txt', binary=False)`
  - 对比实验功能：
    * 相似词检索对比：查询相同词汇，比较两种模型的Top-5相似词
    * 词汇表覆盖率：统计测试词在两种模型中的覆盖情况
    * 可视化对比：PCA降维展示两种模型在词向量空间中的分布差异
  - 实验结果分析：
    * 自训练模型：在特定领域（宋词/新闻）表现更专业，相似词更符合领域特征
    * 预训练模型：词汇覆盖更广，但可能缺乏领域特异性
    * 实际应用：可根据任务需求选择，领域任务用自训练，通用任务用预训练

11. 词向量聚类分析
- 目标：使用K-means等聚类算法观察词语的语义分布
- 实现方案：
  - 提取词向量：`word_vectors = [model.wv[word] for word in vocab]`
  - K-means聚类：`from sklearn.cluster import KMeans; kmeans = KMeans(n_clusters=10); clusters = kmeans.fit_predict(word_vectors)`
  - 可视化：使用t-SNE或UMAP降维后绘制聚类结果
  - 分析：观察同一聚类中的词语是否具有相似语义或主题

12. 词向量用于文本相似度计算
- 目标：实现基于词向量的文本匹配功能
- 实现方案：
  - 句子向量化：平均词向量、TF-IDF加权平均、或使用Sentence-BERT
  - 相似度计算：余弦相似度、欧氏距离等
  - 文本匹配：给定查询文本，返回最相似的文档
  - 评估：在标准数据集上测试匹配准确率

13. 探索不同参数对词向量质量的影响
- 目标：系统分析超参数对词向量质量的影响
- 实现方案：
  - 参数网格搜索：
    - vector_size: [50, 100, 200, 300]
    - window: [3, 5, 10, 15]
    - min_count: [1, 5, 10, 20]
    - epochs: [5, 10, 20, 50]
  - 评估指标：
    - 相似词检索质量（人工评估）
    - 词类比任务准确率
    - 下游任务性能（如文本分类）
  - 结果分析：绘制参数-性能曲线，找出最优参数组合
  - 结论：不同语料和任务可能需要不同的参数设置
