# 算术表达式转换成DAG程序实现说明

## 1. 课设题目要求

设计一个语法制导翻译器，将算术表达式转换成DAG。要求确定一个定义算术表达式的文法，为其设计一个语法分析程序，为每条产生式配备一个语义子程序，按照一遍扫描的语法制导翻译方法，实现翻译程序。

对用户输入的任意一个正确的算术表达式，程序将其转换成DAG输出(可按一定格式输出到指定文件中)。

## 2. 设计思路

### 2.1 整体设计

本程序采用递归下降的语法分析方法，遵循自顶向下的分析方式。程序的主要组成部分包括：

1. **词法分析器**：将输入的字符串转换成Token序列
2. **语法分析器**：根据定义的文法解析Token序列
3. **DAG生成器**：在语法分析的过程中构建DAG
4. **主程序**：读取用户输入、展示结果并保存到文件

### 2.2 文法定义

我们定义的算术表达式文法如下（已消除左递归）：

```
E -> T E'
E' -> + T E' | - T E' | ε
T -> F T'
T' -> * F T' | / F T' | ε
F -> (E) | number
```

其中：
- E 表示表达式
- T 表示项
- F 表示因子
- E' 和 T' 是为了消除左递归引入的非终结符

### 2.3 算法流程

1. 词法分析：
   - 扫描输入字符串，识别数字、运算符和括号
   - 将识别的字符组织成Token序列

2. 语法分析：
   - 按照文法规则自顶向下分析Token序列
   - 为每个产生式关联相应的语义动作

3. DAG构建：
   - 为操作数创建叶子节点
   - 为操作符创建内部节点，并连接到其操作数节点
   - 识别公共子表达式，共享相同的子树

## 3. 实现细节

### 3.1 词法分析器 (Lexer)

词法分析器的主要功能是将输入的字符串转换为Token序列。定义了以下Token类型：
- NUMBER：数字（整数或小数）
- PLUS, MINUS, MULTIPLY, DIVIDE：四则运算符
- LPAREN, RPAREN：左右括号
- END：结束标记

词法分析器通过getNextToken()方法逐个读取并返回下一个Token。

### 3.2 DAG数据结构

DAG由节点组成，每个节点有以下属性：
- ID：节点的唯一标识符
- 类型：操作数或操作符
- 值：对于操作数是数值，对于操作符是运算符号
- 子节点列表：该节点的子节点ID

DAG类提供以下主要操作：
- addLeaf()：添加叶子节点（操作数）
- addOperator()：添加操作符节点
- findEquivalentNode()：查找等价节点，用于识别公共子表达式

### 3.3 语法分析器 (Parser)

语法分析器实现了递归下降的语法分析方法，为文法中的每个非终结符定义了一个解析函数：
- parseE()：解析表达式 E
- parseEPrime()：解析表达式尾 E'
- parseT()：解析项 T
- parseTPrime()：解析项尾 T'
- parseF()：解析因子 F

每个解析函数对应文法中的一个非终结符，并在解析过程中构建DAG。

### 3.4 语义动作

每个产生式对应的语义动作如下：

1. E -> T E'
   - 解析T得到一个子DAG
   - 将该子DAG传递给E'的解析函数

2. E' -> + T E' | - T E' | ε
   - 如果识别到+或-，则解析T得到右操作数子DAG
   - 创建一个新的操作符节点（+或-），连接左操作数和右操作数
   - 将新节点作为左操作数继续解析E'
   - 如果为ε，则直接返回左操作数

3. T -> F T'
   - 解析F得到一个子DAG
   - 将该子DAG传递给T'的解析函数

4. T' -> * F T' | / F T' | ε
   - 如果识别到*或/，则解析F得到右操作数子DAG
   - 创建一个新的操作符节点（*或/），连接左操作数和右操作数
   - 将新节点作为左操作数继续解析T'
   - 如果为ε，则直接返回左操作数

5. F -> (E) | number
   - 如果识别到(，则解析E并期望下一个Token是)
   - 如果识别到数字，则创建一个叶子节点

## 4. 公共子表达式检测

在构建DAG的过程中，程序会检测并合并公共子表达式。实现方法如下：

1. 当添加新节点时，首先检查是否存在等价节点
2. 对于操作数节点，检查是否有相同值的节点
3. 对于操作符节点，检查是否有相同操作符且子节点也相同的节点
4. 对于交换律操作符（+和*），确保左右子节点按ID排序，以便更容易检测公共子表达式

## 5. 结果输出

程序将生成的DAG以表格形式显示在屏幕上，并保存到文件中。输出内容包括：
- 每个节点的ID、类型、值和子节点列表
- DAG的根节点ID

## 6. 测试用例

以下是一些测试用例及其对应的DAG：

1. 简单表达式：`2+3*4`
2. 带括号的表达式：`(1+2)*(3+4)`
3. 复杂表达式：`a+b*(c-d)/(e+f)`
4. 有公共子表达式的表达式：`(a+b)*(c+d)+(a+b)`

## 7. 总结

本程序成功实现了将算术表达式转换成DAG的功能。通过递归下降的语法分析方法，结合语义动作，在解析表达式的同时构建DAG。程序能够识别公共子表达式，避免重复节点，从而得到优化的DAG表示。

未来可以考虑扩展支持更多的运算符（如幂运算、模运算等）和变量赋值操作，以及将DAG转换为三地址代码等优化功能。
