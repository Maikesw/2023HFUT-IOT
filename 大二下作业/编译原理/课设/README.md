# 算术表达式转换成DAG程序

## 项目描述
本程序将算术表达式转换成有向无环图(DAG)。它使用语法分析的方法解析算术表达式，并构建DAG表示。

## 文法定义

```
E -> T E'
E' -> + T E' | - T E' | ε
T -> F T'
T' -> * F T' | / F T' | ε
F -> (E) | number
```

其中:
- E 表示表达式
- T 表示项
- F 表示因子
- E' 和 T' 是为了消除左递归引入的非终结符

## 程序组成
- **lexer.h/cpp**: 词法分析器，将输入表达式转换为Token序列
- **dag.h/cpp**: DAG数据结构及相关操作
- **parser.h/cpp**: 语法分析器，根据文法解析表达式并构建DAG
- **main.cpp**: 主程序入口

## 使用方法

### 在Visual Studio中编译和运行
1. 双击打开`ArithmeticDAG.sln`解决方案文件
2. 在Visual Studio中按F5或点击"本地Windows调试器"按钮运行程序
3. 如果遇到编译错误，请确保您使用的是支持C++11或更高版本的Visual Studio（建议使用Visual Studio 2019或更新版本）

### 使用g++编译（如果已安装g++）
```bash
g++ -std=c++11 main.cpp lexer.cpp dag.cpp parser.cpp -o arithmetic_dag
```

### 使用CMake编译（如果已安装CMake）
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

### 运行
运行编译生成的可执行文件。程序会提示您输入算术表达式。

### 输入示例
程序会提示输入算术表达式，例如：
```
2+3*4
(5+6)*(7-8)
3*(4+5*(6-7))
```

### 输出
程序会将表达式转换为DAG并以表格形式显示在屏幕上，同时保存到`dag_output.txt`文件中。

## DAG表示格式
DAG以节点列表的形式表示，每个节点包含以下信息：
- **ID**: 节点的唯一标识符
- **类型**: 操作数或操作符
- **值**: 节点的值（对于操作数是数字，对于操作符是+,-,*,/等）
- **子节点**: 该节点的子节点ID列表

## 算法原理
1. 对输入的算术表达式进行词法分析，得到Token序列
2. 使用递归下降语法分析方法解析表达式
3. 在解析过程中构建DAG：
   - 对于操作数，创建叶子节点
   - 对于操作符，创建操作符节点并连接子节点
   - 识别公共子表达式，避免重复节点

## 注意事项
- 程序仅支持基本的四则运算(+,-,*,/)和括号
- 操作数仅支持整数和小数
- 程序会检测公共子表达式并在DAG中共享
