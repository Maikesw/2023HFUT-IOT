# 十六进制数输入系统使用说明

## 功能概述
本系统通过中断方式识别多个按键组合的输入情况，实现两位十六进制数的输入和处理功能。

## 硬件连接
- **K1按键**: GPN0 - 辅助输入A-F
- **K2按键**: GPN1 - 十六进制高位输入
- **K3按键**: GPN2 - 十六进制低位输入  
- **K4按键**: GPN3 - 短按比较/长按重置
- **LED1-LED4**: GPK4-GPK7
- **蜂鸣器**: GPF14

## 操作说明

### 1. 十六进制数输入
- **高位输入(K2)**: 按K2键输入十六进制数的高位
  - 单独按K2: 输入0-9 (按1次=1, 按2次=2, ..., 按10次=0)
  - K1+K2组合: 输入A-F (按住K1时按K2: 1次=A, 2次=B, ..., 6次=F)
- **低位输入(K3)**: 按K3键输入十六进制数的低位
  - 单独按K3: 输入0-9 (按1次=1, 按2次=2, ..., 按10次=0)
  - K1+K3组合: 输入A-F (按住K1时按K3: 1次=A, 2次=B, ..., 6次=F)

### 2. 输入确认
- 系统会自动检测输入完成（3秒无按键操作）
- 输入完成后，四个LED会按1秒间隔闪烁，闪烁次数等于十六进制数高位的值

### 3. 比较功能 (K4短按)
输入完成后，短按K4进行比较：
- **比较条件**: 十六进制数对应十进制数的个位 vs 当前星期值
- **个位 > 星期**: 
  - 蜂鸣器按"一长一短"方式鸣叫，次数为十进制数十位的值
  - 四个LED持续闪烁
- **个位 ≤ 星期**:
  - 蜂鸣器按0.5秒间隔鸣叫星期对应的次数
  - LED按单向跑马灯显示(LED1→LED2→LED3→LED4)，循环星期对应的次数

### 4. 系统重置 (K4长按)
长按K4键（超过1秒）可重置系统到初始状态：
- 清除所有输入
- 关闭LED和蜂鸣器
- 返回初始状态

## 状态指示
- **输入状态**: 
  - 按K2时LED2短暂亮起 (0-9输入)
  - 按K3时LED1短暂亮起 (0-9输入)
  - K1+K2时LED1+LED2同时亮起 (A-F输入)
  - K1+K3时LED1+LED3同时亮起 (A-F输入)
- **确认状态**: 四个LED同时闪烁高位次数
- **比较状态**: 根据比较结果显示不同的LED和蜂鸣器模式

## 示例操作

### 示例1: 输入十六进制数1A
1. 按K2一次 (高位=1)
2. 按住K1，然后按K3一次 (低位=A)
3. 等待3秒确认输入
4. LED闪烁1次 (高位值)
5. 短按K4进行比较

### 示例2: 输入十六进制数2F  
1. 按K2两次 (高位=2)
2. 按住K1，然后按K3六次 (低位=F)
3. 等待3秒确认输入
4. LED闪烁2次 (高位值)
5. 短按K4进行比较

### 示例3: 输入十六进制数BC
1. 按住K1，然后按K2两次 (高位=B)
2. 按住K1，然后按K3三次 (低位=C)
3. 等待3秒确认输入
4. LED闪烁11次 (B=11的十进制值)
5. 短按K4进行比较

## 注意事项
1. 所有按键操作都有软件消抖处理
2. 十六进制范围为00-FF
3. 当前星期值设定为2（可在代码中修改xinqi变量）
4. 输入过程中可随时长按K4重置系统
5. 只有在输入确认后才能进行K4短按比较
6. K1必须在按K2/K3之前按住，用于辅助输入A-F

## 技术参数
- 定时器频率: 1Hz (1秒间隔)
- 输入超时: 3秒
- 消抖延时: 50ms
- 长按判断: 1秒
